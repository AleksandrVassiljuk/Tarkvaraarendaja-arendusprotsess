Programmeerimise alused

Sissejuhatus

Programmeerimine tähendab arvutile juhiste andmist. Nende juhiste abil saab arvuti teha erinevaid ülesandeid. Programmid koosnevad koodist, mis kirjutatakse kindlas programmeerimiskeeles. Mina õppisin Python keelt. Programmeerimise eesmärk on lahendada probleeme ja automatiseerida tööd.

Programmi töö toimub samm-sammult. Arvuti loeb koodi ülevalt alla ja täidab käske järjest. Kui koodis on viga, siis programm ei pruugi töötada või annab veateate. 

print("Tere maailm")

Muutujad

Muutuja on koht, kuhu saab salvestada andmeid. Näiteks saab salvestada nime, vanuse või arvu. Pythonis ei pea eraldi ütlema, mis tüüpi muutuja on.

Muutujaid kasutatakse peaaegu igas programmis, sest ilma nendeta ei saa andmeid hoida. 

nimi = "Aleksandr"
vanus = 17
arv = 10

print(nimi)
print(vanus)
print(arv)

Tingimuslaused

Tingimuslaused aitavad programmil otsuseid teha. Näiteks saab kontrollida, kas arv on suurem või väiksem.

Kui tingimus on tõene, siis tehakse üks tegevus. Kui ei ole tõene, tehakse teine tegevus. 

a = 10

if a > 5:
    print("Arv on suurem kui 5")
else:
    print("Arv on väiksem või võrdne 5")

Tsüklid

Tsükleid kasutatakse siis, kui on vaja sama asja mitu korda korrata. Näiteks saab printida numbreid või käia läbi listi kõik elemendid.

Kõige rohkem kasutatakse for-tsüklit ja while-tsüklit. 

for i in range(5):
    print(i)

Funktsioonid

Funktsioon on koodiplokk, mida saab mitu korda kasutada. See aitab vältida korduvat koodi.

Funktsioonile saab anda ka sisendeid (parameetreid). 

def tervitus(nimi):
    print("Tere " + nimi)

tervitus("Mari")
tervitus("Jaan")

Järjendid

Järjend on andmestruktuur, kuhu saab panna mitu väärtust korraga. Näiteks saab hoida numbreid või nimesid.

Järjendi kaudu saab käia kõik elemendid läbi tsükliga. 

numbrid = [1, 2, 3, 4, 5]

for n in numbrid:
    print(n)

Sõnastikud

Sõnastik on andmestruktuur, kus andmed on võtme ja väärtuse kujul.

Näiteks saab hoida inimese nime ja vanust. 

isik = {
    "nimi": "Karl",
    "vanus": 18
}

print(isik["nimi"])
print(isik["vanus"])

Objektorienteeritud programmeerimine

Objektorienteeritud programmeerimine (OOP) tähendab, et programm koosneb objektidest ja klassidest.

Klass on nagu mudel ja objekt on selle tegelik näide. 

class Auto:
    def __init__(self, mark, aasta):
        self.mark = mark
        self.aasta = aasta

    def kuva(self):
        print(self.mark, self.aasta)

auto1 = Auto("BMW", 2020)
auto1.kuva()

Failide kasutamine

Failidega saab andmeid salvestada ja hiljem lugeda. See on kasulik, kui andmeid on vaja säilitada. 

fail = open("andmed.txt", "r")
sisu = fail.read()
print(sisu)
fail.close()

Näidisülesanne

Ülesanne: Kirjuta programm, mis küsib kasutaja nime ja vanuse ning kuvab need ekraanile.

See ülesanne aitab õppida sisendi ja väljundi kasutamist. 

nimi = input("Sisesta nimi: ")
vanus = input("Sisesta vanus: ")

print("Nimi:", nimi)
print("Vanus:", vanus)

Kokkuvõte

Programmeerimise alustes õppisin, kuidas kirjutada lihtsaid programme Pythonis. Õppisin muutujad, tingimuslaused, tsüklid, funktsioonid, järjendid, sõnastikud ja OOP põhimõtted.

Need oskused on väga olulised, sest nende abil saab teha suuremaid ja keerulisemaid programme.
